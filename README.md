# Application Platform

Reusable application foundation built with:

- Java
- Spring Boot
- Spring Security
- React
- PostgreSQL
- Docker

## Purpose

This project provides a reusable foundation for building
business applications without repeatedly implementing
authentication, authorization, user management, and common
application infrastructure.

## Planned Modules

- Authentication
- Authorization
- User Management
- Role Management
- Permission Management
- Security
- Audit
- Common Infrastructure

## Technology Stack

### Backend
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL

### Frontend
